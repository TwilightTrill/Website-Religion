> **วัตถุประสงค์:** นำองค์ความรู้ในการออกแบบและพัฒนาเว็บไซต์มาบูรณาการกับวันสำคัญทางพระพุทธศาสนา และพัฒนาทักษะการเรียนรู้ในศตวรรษที่ 21 (Life and Career Skills / Information, Media & Technology Skills)

## 🚀 วิธีการเปิดใช้งานเว็บไซต์ (ไม่ต้องติดตั้ง Server / ไม่ต้องรัน npm)

ตามเงื่อนไขข้อกำหนดของกิจกรรม **"เกณฑ์ข้อ 5: ไม่มีการใช้งานฐานข้อมูล เว็บเพจต้องสามารถเปิดได้ด้วย browser chrome ทันทีโดยไม่ต้องรันบน server"**

ดังนั้น **ไม่ต้องรัน `npm run dev`** ครับ สามารถเปิดใช้งานได้ 3 วิธีง่ายๆ ดังนี้:

1. **วิธีที่ 1 (สะดวกที่สุด):** ดับเบิ้ลคลิกไฟล์ `เปิดเว็บไซต์.bat` ที่อยู่ในโฟลเดอร์นี้ ระบบจะเปิด Google Chrome หรือบราวเซอร์หลักขึ้นมาทันที
2. **วิธีที่ 2:** ดับเบิ้ลคลิกไฟล์ `index.html` ได้โดยตรง
3. **วิธีที่ 3:** คลิกขวาที่ไฟล์ `index.html` -> เลือก **Open with (เปิดด้วย)** -> เลือก **Google Chrome**

## 📂 โครงสร้างเว็บไซต์และไฟล์ทั้งหมด

```text
Website Religion/
├── index.html            # หน้าแรก (Hero, ตัวนับถอยหลัง, มัลติมีเดีย YouTube/TikTok/Facebook, การ์ดวันสำคัญ, แบบทดสอบ)
├── makha-bucha.html      # หน้าข้อมูลวันมาฆบูชา (จาตุรงคสันนิบาต, โอวาทปาฏิโมกข์)
├── visakha-bucha.html    # หน้าข้อมูลวันวิสาขบูชา (ประสูติ ตรัสรู้ ปรินิพพาน, วันสำคัญสากลโลก UNESCO)
├── asalha-bucha.html     # หน้าข้อมูลวันอาสาฬหบูชา (ปฐมเทศนา ธัมมจักกัปปวัตตนสูตร, พระรัตนตรัยครบองค์สาม)
├── khao-phansa.html      # หน้าข้อมูลวันเข้าพรรษา (ประวัติการจำพรรษา, ถวายเทียนพรรษา)
├── ok-phansa.html        # หน้าข้อมูลวันออกพรรษา (วันมหาปวารณา, ประเพณีตักบาตรเทโวโรหณะ)
├── about.html            # หน้าเอกสารทฤษฎีการออกแบบเว็บไซต์ และ HCI (ระบุวัตถุประสงค์ ทฤษฎีสี ลำดับสายตา และอ้างอิง)
├── เปิดเว็บไซต์.bat       # ไฟล์ช็อตคัตสำหรับดับเบิ้ลคลิกเปิดเว็บไซต์ใน Chrome ทันที
├── css/
│   └── style.css         # ระบบสไตล์ CSS (Design System, Dark & Gold Theme, A11y, แอนิเมชัน, Responsive)
└── js/
    └── script.js         # JavaScript เชิงปฏิสัมพันธ์ (HCI Toolbar, แบบทดสอบธรรมะ, ตัวนับเวลา, Web Audio Bell)
```

## 🌟 จุดเด่นที่ตรงตามเกณฑ์การพิจารณา 100%

| เกณฑ์การพิจารณา | สิ่งที่พัฒนาขึ้นในเว็บไซต์ |
|---|---|
| **1. เนื้อหาครบถ้วน สมบูรณ์ และมีมัลติมีเดีย** | - รวบรวม 5 วันสำคัญหลักอย่างลึกซึ้ง พร้อมไทม์ไลน์และประเพณี<br>- มีเมนูเชื่อมโยงระหว่างหน้าเว็บเพจครบถ้วน<br>- เมนูเชื่อมโยงเว็บไซต์ทางการ (สนง.พระพุทธศาสนา, กรมการศาสนา, ธรรมะไทย, 84000.org)<br>- หน้าแรกแสดงวิดีโอจาก **YouTube, TikTok, Facebook** พร้อมแท็บตัวกรอง |
| **2. ทฤษฎีการออกแบบเว็บที่ดี** | - **ทฤษฎีสี (Color Psychology):** Deep Cosmos Blue (#0A0A14) ตัดด้วย Temple Gold (#D4A847) และ Saffron Orange (#E88D30) สื่อถึงความสงบและปัญญา<br>- **Visual Hierarchy & Typography:** ใช้ฟอนต์ Prompt (หัวข้อ) และ Sarabun (เนื้อหา) สบายตา<br>- **Gestalt Principles:** จัดสัดส่วน Proximity และ Similarity สวยงามและสมดุล |
| **3. ปฏิสัมพันธ์มนุษย์กับคอมพิวเตอร์ (HCI)** | - **A11y Toolbar:** ปุ่มปรับขนาดตัวอักษร 3 ระดับ (A-, A, A+) รองรับผู้สูงอายุและผู้มีปัญหาทางสายตา<br>- **Interactive Dhamma Quiz:** แบบทดสอบ 5 ข้อ พร้อมระบบคะแนน เฉลย และ Instant Feedback ทันที<br>- **Web Audio Bell Chime:** สังเคราะห์เสียงระฆังธรรมมะ 528Hz เพื่อความสงบใจ โดยไม่ต้องพึ่งพาไฟล์เสียงภายนอก<br>- **Real-time Countdown Timer:** ตัวนับถอยหลังสู่วันสำคัญทางศาสนาถัดไป<br>- **3D Tilt Card Effects & Scroll Reveal Animations** |
| **4. เทคโนโลยีที่อนุญาต** | ใช้งาน HTML5, Vanilla CSS3, JavaScript (ES6+) และ Web Audio API มาตรฐาน ไม่มีการใช้ฐานข้อมูล |
| **5. การเปิดใช้งานทันที** | เปิดใช้งานบน Google Chrome ผ่าน `file:///` ได้ทันที 100% ไม่ต้องรันเซิร์ฟเวอร์ |
| **6. แหล่งอ้างอิงถูกต้อง** | ระบุแหล่งอ้างอิงของเนื้อหาและภาพถ่าย (Unsplash CC0 License) รวมถึงลิงก์วิดีโออย่างถูกต้องตามหลักวิชาการ |
